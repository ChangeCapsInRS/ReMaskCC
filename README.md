# ReMask-CC: RemoteCLIP-Guided Semantic Change Masking for Remote Sensing Image Change Captioning


This repository is associated with our manuscript: **ReMask-CC: RemoteCLIP-Guided Semantic Change Masking for Remote Sensing Image Change Captioning** The paper has been submitted to **IEEE Geoscience and Remote Sensing Letters (GRSL)**. The source code, model implementation, training scripts, and related experimental materials will be made publicly available in this repository upon acceptance of the manuscript. Currently, this repository serves as a placeholder for the submitted paper. The complete implementation will be released after the acceptance of the paper in **IEEE GRSL**.
